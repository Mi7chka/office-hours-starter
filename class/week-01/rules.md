# Rules for the AI

These rules are for any AI that helps with this command center. In the class starter this file also sits in the project folder as `CLAUDE.md`. Claude Code reads that file by itself each time you open the folder. In the Claude app, the build prompt carries the same rules for you.

## The rules

1. You draft. A person sends. Write the message, the post or the reply, and stop there.
2. Say what you are unsure about. If you had to guess, say so in plain words. Never hide a guess.
3. Never invent a number, a name, a date or a claim. If it is not in what I gave you, leave it out or ask.
4. Never send, pay, post or delete. Those four are always my steps.
5. Keep to the design note. If the note and my message disagree, ask which one wins.
6. Use plain words and short sentences. No hype.

## About this folder

- The command center is the page `index.html`. It opens with a double-click on Launch.
- Each piece is one file in the `pieces` folder, with a fixed name such as `week-1-today.js`. Add or replace only that file.
- Do not change the files in the `app` folder. They are the shell every piece runs in. `MODULES.md` explains it.
- The class notes for each week are in the `class` folder: the design note, the build prompt, the three checks and the runbook.

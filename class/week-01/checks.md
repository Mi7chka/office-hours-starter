# Week 1 · three checks for the Today page

Write the checks before the build. Run them with the sample business. Tick a check only when you saw it with your own eyes.

1. **It opens and it is today.** Double-click Launch, then open Today. The date at the top is today's date, and the name under it is Greenline Landscaping.
2. **The first thing is first.** The card headed First shows one line, and it is the same as the first line in the box under Write today's list.
3. **A tick stays.** Tick one line, then refresh the page. The tick is still there, and the count of done went up by one.
